1. What is a Linked List?
    A Linked List is a linear data structure where elements are stored in separate objects called nodes.
    Unlike an array, nodes are not necessarily stored next to each other in memory.

    Each node contains:
        [ Data | Next ]

    Example:
        10 → 20 → 30 → 40 → null

    Each node knows:
        its own data
        where the next node is

    first node -> head.
    last node points to null.


2. Linkedlist vs Array
| Feature                 | Array                | Linked List            |
| ----------------------- | -------------------- | ---------------------- |
| Memory                  | Contiguous           | Non-contiguous         |
| Access by index         | O(1)                 | O(n)                   |
| Search                  | O(n)                 | O(n)                   |
| Insert at beginning     | O(n)                 | O(1)                   |
| Delete beginning        | O(n)                 | O(1)                   |
| Insert after known node | O(1)                 | O(1)                   |
| Random access           | Yes                  | No                     |
| Extra memory            | Low                  | Higher due to pointers |
| Cache friendly          | Yes                  | Less cache friendly    |
| Resizing                | May require resizing | Dynamic                |

Insertion/deletion is O(1) when we already have a reference to the relevant node. Finding that position can still take O(n).
For example:
    10 → 20 → 30 → 40
    If you already have the node 20, inserting 25 after it is:
    10 → 20 → 25 → 30 → 40  ->  O(1).
    But if you first have to search for 20, that's O(n).


3. What is a Node?
    A node is the fundamental building block.
    For a singly linked list:
        Node
            ├── data
            └── next
    conceptually:
        class Node {
            constructor(data) {
                this.data = data;
                this.next = null;
            }
        }
    suppose:
        const node1 = new Node(10);
        const node2 = new Node(20);
        const node3 = new Node(30);
    initially:
        node1     node2     node3
        10        20        30
        ↓         ↓         ↓
        null      null      null
    Connect them:
        node1.next = node2;
        node2.next = node3;
    Now:
        10 -> 20 -> 30 -> null


4. Head
    The head is the reference to the first node.
        head
        ↓
        10 → 20 → 30 → null
    If:
        head = node1;
    then:
        head
        ↓
        10 → 20 → 30 → null
    Important:
    The head is not necessarily the node itself conceptually.
    It is a reference/pointer to the first node.
